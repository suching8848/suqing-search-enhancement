[h1]蘇清的搜索增强 | SuQing's Search Enhancement[/h1]

[h2]中文[/h2]
仿的mc的jei的搜索逻辑。用名称、来源模组、完整物品 ID 和可选拼音查找随身及附近物品，在现有详细列表中高亮、计数并默认将匹配组置顶。

[b]打开与设置[/b]
F8 打开增强面板，选择随身／附近。八项个人选项位于“设置 → 模组设置 → 蘇清的搜索增强”：原框接入、计数、匹配组置顶和可用时的拼音默认开启；左键原框弹窗、展开帮助和右键入口默认关闭，快捷键默认 F8。核心使用游戏自带设置接口，无外部硬前置。
独立沙盒选项位于“沙盒设置 → 蘇清的搜索增强 → 原搜索框接管方式”。默认“全部接管”；可选“仅特殊语法接管”，普通单词／中文名称保留原搜索方法与黄色高亮，输入 @、&、-、|、引号或空格 AND 才启动增强。两端空白不算特殊语法；F8 面板始终增强。旧档缺少该值时使用默认，不自动修改存档。
增强命中行使用紫色边框和原搜索黄色高亮；选中／悬停保留原背景及命中紫边。置顶跟随过滤、原地排序和绘制刷新，组内保留原排序；清空或关闭置顶恢复原排序。拖拽、普通鼠标按住及框选期间延后重排。拖拽结束后恢复置顶，无需再次点击物品列表。

[b]搜索示例[/b]
酿酒：名称部分匹配。
@舌尖 酿酒 -书：来源 AND 名称，排除书。
&Chinesecuisine.BrewingBook34：完整物品 ID 相等匹配，忽略 ASCII 大小写。
扳手 | 锤子：任一组；组内空格为 AND，多个词也属于特殊语法。
@"Mod Name" "item name"：引号将含空格文字组合为一个条件。
@原版 或 @vanilla：按游戏识别的真实来源查询。
名称、类型名和来源显示名忽略 ASCII 大小写，宽松处理空白、连字符、下划线和拼音分音撇号；不纠错。完整 ID 不作模糊或拼音匹配。@ModID 按真实 ID 查找，Base 命名空间与工坊 ID 不等于来源。引号不要求精确空格。

[h2]English[/h2]
Search logic inspired by Minecraft JEI. Find carried and nearby items by name, source mod, full item ID and optional pinyin. Mark/count matches and prioritize matching groups in existing detailed lists.

[b]Opening and settings[/b]
F8 opens Carried/Nearby search. Eight personal settings under Options > Mod Options > SuQing's Search Enhancement control field integration, counts, priority and available pinyin (on by default), click popup, expanded help and context entry (off), and the shortcut (F8). The core uses the game's built-in settings API with no external hard requirement.
A separate Sandbox Options > SuQing's Search Enhancement > Existing search-field handling setting defaults to all searches. Special syntax only keeps ordinary words/Chinese names with native matching and yellow highlights. @, &, -, |, quotes and whitespace AND activate enhancement; surrounding whitespace alone does not. The F8 panel always enhances searches. Missing values in old worlds use the default without editing the save.
Enhanced hits have purple outlines plus original yellow search highlights. Selection/hover retain their backgrounds and the match outline. Priority follows filtering, in-place sorting and rendering refreshes while preserving order within groups. Clearing or disabling priority restores native order. Dragging, ordinary mouse holds and marquee selection defer reordering. Priority resumes after drag release without another item-list click.

[b]Queries[/b]
brewing: partial name match.
@"Mod Name" brewing -book: source AND name, excluding book.
&Chinesecuisine.BrewingBook34: exact full ID, ignoring ASCII case.
wrench | hammer: either group; whitespace means AND and activates special handling.
"item name": quotes group text containing spaces.
@vanilla: game-identified vanilla source.
Names, type names and source display names ignore ASCII case and tolerate whitespace, hyphens, underscores and pinyin apostrophes. No spelling correction. Full IDs never use partial/pinyin matching. @ModID uses the real source ID, distinct from Base namespaces or Workshop IDs. Quotes do not enforce exact whitespace.

[b]Optional integrations and scope[/b]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3657184750]Pinyin Search (yxjs_PinYinSearch 1.3)[/url]: full spelling, initials and polyphonic alternatives, limited by its dictionary. NIUROUBING/NRB can find 牛肉饼; M110BQ can find M110 步枪. Its code/dictionary are not bundled.
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3437629766]CleanUI 2.10.4 / 2.10.5[/url]: field integration retains categories and synchronizes text/scope. Other UIs can use F8; custom fields require adapters.
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=2847184718]Proximity Inventory[/url]: listed, readable physical sources with instance-based deduplication. All integrations are optional.
Supports B42.21.0 and B42.22.2 single-player detailed lists; icon grids are not adapted. Carried reads listed inventory/bags; Nearby reads accessible, explored containers and visible floor items. No world scanning, exploration or loot generation. Items/save structures are unchanged; queries are session-only. Exit normally, disable and restart to remove UI behavior. Manual/Workshop copies share one Mod ID; keep one loading source.

[b]Validation and assets[/b]
Version 0.1.4-rc.3 restores row reuse and priority when toggling matching stacks in CleanUI 2.10.5, with selection and Shift anchors preserved. The first hits appear before the scan completes. B42.21.0 and B42.22.2 each passed 1,302 offline assertions. In-game testing is pending.
Cover/separate transparent icon use AI-assisted artwork; the character is not an in-game skin/outfit. Thanks to integration authors; upstream rights remain theirs.
